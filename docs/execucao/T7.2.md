# T7.2 — Redirecionamento dos logs para o volume

**Data (UTC):** 2026-10-29T03:50:24Z
**Fase:** 7 — logs no volume e rotação
**Status:** concluída
**Evidências:** `evidencias/T7.2-dropin-cpu.txt` · `T7.2-dropin-cpu.png` · `T7.2-dropin-memory.*` · `T7.2-dropin-io.*` · `T7.2-restart.*`

## Objetivo

Mudar o destino dos logs das unit files, sem editar as units originais, e
reiniciar os serviços para passar a escrever no volume.

## Comandos executados

```bash
cat payload/logs/dropin/cpu.conf | ssh ... 'sudo install -d /etc/systemd/system/app-cpu.service.d
    sudo tee /etc/systemd/system/app-cpu.service.d/volume-logs.conf'
# idem para memory e io
ssh ... 'sudo systemctl daemon-reload; sudo systemctl restart app-cpu app-memory app-io
    systemctl is-active app-cpu app-memory app-io
    systemctl show -p StandardOutput -p StandardError app-cpu app-memory app-io'
```

## O que aconteceu

Em vez de editar `/etc/systemd/system/app-cpu.service`, cada serviço ganhou um
**drop-in**:

```ini
[Service]
StandardOutput=append:/mnt/atividade3-logs/cpu/app.log
StandardError=append:/mnt/atividade3-logs/cpu/app.log
ReadWritePaths=/var/log/atividade3/cpu /mnt/atividade3-logs/cpu
```

O drop-in substitui `StandardOutput`/`StandardError` e **soma** um caminho à
lista de `ReadWritePaths` (diretivas de lista acumulam entre a unit e o
drop-in; as de valor único substituem). Sem esse acréscimo, o `ProtectSystem`
da unit base impediria a escrita no volume.

A vantagem do drop-in é ser reversível: apagar o arquivo e dar `daemon-reload`
volta ao estado anterior, sem ter a unit original modificada.

Depois do `restart`, os três serviços ficaram `active` e o `systemctl show`
confirmou o modo `append` em todos. Ele mostra o nome da diretiva, não o
caminho — o caminho é provado na T7.3 com `ls` e `stat`.

## Saída

```text
[Service]
StandardOutput=append:/mnt/atividade3-logs/cpu/app.log
StandardError=append:/mnt/atividade3-logs/cpu/app.log
ReadWritePaths=/var/log/atividade3/cpu /mnt/atividade3-logs/cpu

active
active
active

StandardOutput=append
StandardError=append
```

## Decisões

- Drop-in em vez de editar a unit: mudança pequena, isolada e reversível.
- Os arquivos antigos em `/var/log/atividade3` ficaram no lugar, como histórico
  da fase 5; não são mais escritos.

## Problemas e pendências
