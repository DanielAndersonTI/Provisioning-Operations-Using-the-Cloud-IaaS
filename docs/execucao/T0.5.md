# T0.5 — Cliente OpenStack

**Data (UTC):** 2026-10-29T02:28:57Z
**Status:** concluída
**Evidências:** `evidencias/T0.5-openstack-version.txt`, `evidencias/T0.5-openstack-version.png`

## Objetivo

Confirmar que o cliente responde e que o `psutil` está disponível para o
monitor da VM.

## Comandos executados

```bash
openstack --version
python3 -c 'import psutil; print("psutil", psutil.__version__)'
```

## O que aconteceu

`openstack 5.8.0` — é a versão empacotada no Ubuntu 22.04, não a mais recente do
PyPI. Ela cobre tudo o que a atividade pede (Nova, Glance, Neutron, Cinder e
Octavia); se algum comando específico do Octavia não existir, a alternativa é
instalar o cliente via `pip` num virtualenv.

`psutil 5.9.0` está disponível para o `scripts/monitor.py`.

## Decisões

- Manter o cliente do `apt` para não misturar pacotes de sistema e do `pip`.
