# T8.1 — Estado do balanceador antes da publicação

**Data (UTC):** 2026-10-29T04:13:0xZ
**Fase:** 8 — aplicações pelo balanceador
**Status:** concluída
**Evidências:** `evidencias/T8.1-listener-list.txt` · `T8.1-listener-list.png`

## Objetivo

Reler os listeners do `poi-atividades` imediatamente antes de criar os meus, para
escolher portas livres. O balanceador é compartilhado com a turma e a lista muda
ao longo do dia.

## Comandos executados

```bash
openstack loadbalancer listener list -c name -c protocol -c protocol_port
```

## O que aconteceu

A lista mostrou os listeners dos outros grupos e os meus dois já criados
(`ssh-daniel-ranya` na 2222 e os de CPU/memória). As portas 8100–8102
continuavam livres, então a faixa pôde ser mantida.

Consultar de novo em vez de reaproveitar a lista do T1.5 não é preciosismo: como
o LB é compartilhado, outro grupo pode ter ocupado 8101 entre a leitura inicial e
este momento, e a criação falharia com conflito de porta.

## Saída

A íntegra está em `T8.1-listener-list.txt`; as portas em uso no momento estão
listadas na coluna `Protocol Port` da tabela.

## Decisões

- Portas externas 8100/8101/8102 para cpu/memory/io, próximas e de fácil leitura
  no formulário de entrega.
- Ler a lista imediatamente antes de criar, não no início do trabalho.

## Problemas e pendências

Nenhum.
