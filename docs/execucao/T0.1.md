# T0.1 — Identidade da máquina de acesso

**Data (UTC):** 2026-10-29T02:26:03Z
**Status:** concluída
**Evidências:** `evidencias/T0.1-host-info.txt`

## Objetivo

Registrar qual máquina executa a CLI do OpenStack, para que os resultados
possam ser atribuídos a um ambiente conhecido.

## Comandos executados

```bash
hostnamectl; uname -a; whoami; id; nproc; free -m; df -h /
```

## O que aconteceu

A VDI fornecida pelo professor é uma **Ubuntu 22.04 LTS** (`kernel
5.15.0-25-generic`), rodando dentro do VirtualBox (`Virtualization: oracle`).
Ela tem **2 vCPUs**, **1.977 MiB de RAM** e um disco de **232 GB** com apenas
8,3 GB usados. O usuário é `osboxes`, com `sudo` disponível — é por ele que as
ferramentas foram instaladas.

Essa máquina é apenas o **cliente** da nuvem: é dela que os comandos
`openstack` saem. A máquina virtual da atividade é outra, criada pelo Nova com
a imagem `ubuntu-24.04`.

## Saída

```
Operating System: Ubuntu 22.04 LTS
Kernel: Linux 5.15.0-25-generic
nproc: 2
Mem: 1977 MB total
/dev/sda2 232G 8.3G usados
```

## Decisões

- A VM da atividade foi criada com 2 vCPU e 2.048 MB, deixando 4 GB para o
  host e os demais processos.
