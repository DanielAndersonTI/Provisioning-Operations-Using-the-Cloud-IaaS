# T10.1 — Dependência do monitor na VM

**Data (UTC):** 2026-10-29T05:29:57Z

**Status:** concluída
**Evidência:** `evidencias/T10.1-psutil.txt` · `T10.1-psutil.png`

## Objetivo

Garantir que o monitor de recursos roda **dentro da VM**, porque só o sistema
operacional de dentro enxerga a CPU, a memória e o swap que o OpenStack
provisionou para ela.

## Comandos executados

```bash
ssh ... ubuntu@150.165.85.77 'python3 -c "import psutil; print(\"psutil\", psutil.__version__)"'
```

O script da fase testa o `import` antes: se faltar, instala `python3-psutil`
pelo `apt` e só então registra a evidência.

## O que aconteceu

A VM já tinha `psutil 5.9.8` disponível no Python do sistema (Ubuntu 24.04), sem
precisar de instalação. O `import` executou sem erro dentro da VM, ligada pela
VIP na porta 2222.

## Saída

```text
psutil 5.9.8
[exit 0]
```

## Decisões

- Medir por `psutil`, e não por `/proc` lido à mão: o `/proc/stat` dá os
  contadores acumulados e exigiria calcular a diferença entre amostras; o
  `psutil.cpu_percent` já devolve a média da janela de amostragem.
- Verificar a dependência **antes** de disparar a matriz: uma execução de 45 s
  que falhasse no monitor no fim teria de ser repetida inteira.
