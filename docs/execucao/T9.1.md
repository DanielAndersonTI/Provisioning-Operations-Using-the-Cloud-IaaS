# T9.1 — Estado da VM antes do snapshot

**Data (UTC):** 2026-10-29T05:16:52Z
**Fase:** 9 — snapshot da VM configurada
**Status:** concluída
**Evidências:** `evidencias/T9.1-before.txt` · `T9.1-before.png`

## Objetivo

Registrar o estado exato da VM no instante anterior ao snapshot, para que o
snapshot seja atribuível a uma configuração conhecida.

## Comandos executados

```bash
openstack server show vm-daniel-ranya -c name -c status -c addresses -c flavor -c image -f yaml
```

## O que aconteceu

| Campo | Valor |
| --- | --- |
| nome | `vm-daniel-ranya` |
| status | `ACTIVE` |
| endereço | `provider=10.5.9.15` |
| flavor | `general.small` (`7441c7d9-...`) |
| imagem base | `ubuntu-24.04` (`8ac7c385-...`) |

Essa é a VM já com tudo o que as fases 5 a 8 fizeram: aplicações instaladas e
habilitadas no boot, volume de 1 GB formatado e no `fstab`, logs no volume com
rotação configurada.

## Saída

```yaml
addresses:
  provider:
  - 10.5.9.15
flavor: general.small (7441c7d9-2648-4a33-907e-4d28c2270da3)
image: ubuntu-24.04 (8ac7c385-d5d2-488a-82a4-4e1b57ffa6b1)
name: vm-daniel-ranya
status: ACTIVE
```

## Decisões

- Fazer o snapshot depois de tudo configurado e **depois** dos testes de falha,
  que deixaram os três serviços de volta em `ONLINE`.

## Problemas e pendências

Nenhum.
