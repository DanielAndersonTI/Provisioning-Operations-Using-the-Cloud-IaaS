## Objetivo

Fazer os comandos `openstack loadbalancer ...` existirem na VDI. T1.3 mostrou que
o cliente base não os traz.

## Comandos executados

```bash
sudo apt-get install -y python3-octaviaclient
openstack loadbalancer list
```

## O que aconteceu

Depois de instalar o pacote, `openstack loadbalancer list` passou a responder e
devolveu o balanceador `poi-atividades`. A partir daí, todas as operações de
listener, pool, monitor e membro ficaram disponíveis.

Vale registrar o motivo de o erro de T1.3 parecer "comando inexistente" e não
"erro de permissão": a CLI carrega os comandos por plugin, e o Octavia é um
plugin separado do pacote principal.
