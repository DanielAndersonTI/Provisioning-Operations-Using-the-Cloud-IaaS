# T6.4 — Prova de persistência com reboot

**Data (UTC):** 2026-10-29T03:36:56Z
**Fase:** 6 — volume de 1 GB para logs
**Status:** concluída
**Evidências:** `evidencias/T6.4-marker.txt` · `T6.4-marker.png` · `T6.4-reboot.*` · `T6.4-after-reboot.*`

## Objetivo

Provar de verdade que a montagem sobrevive ao reboot e que os dados continuam
lá. Escrever no `fstab` e supor que funciona não é prova.

## Comandos executados

```bash
ssh ... 'date -u +%FT%TZ | sudo tee /mnt/atividade3-logs/marca-antes-do-reboot.txt'
ssh ... 'sudo reboot'
# espera a VM voltar a aceitar SSH (laço com timeout)
ssh ... 'uptime -p; findmnt /mnt/atividade3-logs; ls -l /mnt/atividade3-logs
    sudo cat /mnt/atividade3-logs/marca-antes-do-reboot.txt; df -h /mnt/atividade3-logs
    systemctl is-active app-cpu app-memory app-io'
```

## O que aconteceu

Antes de reiniciar, gravei um arquivo com o instante do teste dentro do volume:
`2026-10-29T03:36:57Z`. Esse arquivo só pode sobreviver ao reboot se estiver
**no volume** — se a montagem não voltasse, o arquivo apareceria no disco raiz,
onde `/mnt/atividade3-logs` seria apenas um diretório vazio.

Depois do reboot a VM respondeu com `up 0 minutes`, confirmando que era um boot
novo. E o volume voltou:

| Verificação | Resultado |
| --- | --- |
| `findmnt` | `/mnt/atividade3-logs` em `/dev/vdb`, `ext4`, `rw` |
| Conteúdo | `lost+found`, `teste.txt` e `marca-antes-do-reboot.txt` |
| Marca lida de volta | `2026-10-29T03:36:57Z` |
| Espaço | 974 MB, 32 KB usados |
| `app-cpu`, `app-memory`, `app-io` | `active` |

Os três serviços voltarem `active` sem ninguém ter digitado nada é metade da
prova do `enable` da T5.4 — a outra metade é o volume voltar montado.

## Decisões

- Reiniciar a VM no meio do trabalho, com a VM já em uso, e não num momento
  "arrumado" depois: é a única forma de provar que a configuração está no disco
  e não na sessão.
- Esperar o SSH voltar em vez de `sleep` fixo: o tempo de boot varia.

## Problemas e pendências

Nenhum. O reboot custou cerca de 50 s de indisponibilidade, que é esperado para
1 vCPU.
