**Data (UTC):** 2026-10-29T02:26:04Z – 02:28:54Z
**Status:** concluída
**Evidências:** `evidencias/T0.4-install-tools.txt`, `evidencias/T0.4-install-tools.png`

## Objetivo

Instalar na VDI o cliente OpenStack e as ferramentas usadas nas fases
seguintes.

## Comandos executados

```bash
sudo apt-get update -qq
sudo apt-get install -y jq curl tmux imagemagick fonts-dejavu-core \
     python3-pip python3-psutil python3-openstackclient
```

## O que aconteceu

A instalação terminou com código 0 em cerca de 2 min 50 s. O `apt` reiniciou
`rsyslog`, `ssh` e `udisks2` (rotina de `needrestart`), o que não afetou a
sessão SSH em curso.

Cada pacote tem uma função no trabalho:

| Pacote | Uso |
| --- | --- |
| `python3-openstackclient` | a CLI propriamente dita |
| `python3-psutil` | monitor de CPU/RAM dentro da VM da atividade |
| `imagemagick` + `fonts-dejavu-core` | gera o `.png` de cada evidência a partir da transcrição |
| `jq` | extrai IDs e IPs das saídas JSON da CLI |
| `tmux` | mantém a sessão viva se o SSH cair durante a coleta |

## Problemas

- O `unattended-upgrades` da imagem disparou durante a execução e disputou o
  lock do `apt`; o `apt-get` esperou e concluiu normalmente.
