# T4.1 — Balanceador para acesso SSH

**Data (UTC):** 2026-10-29T03:11:0xZ
**Fase:** 4 — acesso SSH pelo balanceador
**Status:** concluída
**Evidências:** `evidencias/T4.1-listener-create.txt` · `T4.1-pool-create.*` · `T4.1-hm-create.*` · `T4.1-member-create.*` · `T4.1-listener-show.*` · `T4.1-pool-status.*`

## Objetivo

Publicar o SSH da VM na VIP do balanceador `poi-atividades`, já que a VM não tem
endereço público. É a primeira prova de que o caminho
`VDI → 150.165.85.77:2222 → 10.5.9.15:22` funciona.

## Comandos executados

```bash
openstack loadbalancer listener create --name ssh-daniel-ranya --protocol TCP --protocol-port 2222 poi-atividades --wait
openstack loadbalancer pool create --name pool-ssh-daniel-ranya --lb-algorithm ROUND_ROBIN --listener ssh-daniel-ranya --protocol TCP --wait
openstack loadbalancer healthmonitor create --name hm-ssh-daniel-ranya --delay 5 --timeout 4 --max-retries 3 --type TCP pool-ssh-daniel-ranya --wait
openstack loadbalancer member create --name vm-daniel-ranya --subnet-id 17de9c72-e5dc-4da0-ae0a-013f7e42400e --address 10.5.9.15 --protocol-port 22 pool-ssh-daniel-ranya --wait
openstack loadbalancer listener show ssh-daniel-ranya
```

## O que aconteceu

A estrutura criada é a mínima para publicar um serviço no Octavia:

| Objeto | Nome | Função |
| --- | --- | --- |
| listener | `ssh-daniel-ranya` | aceita TCP em `150.165.85.77:2222` |
| pool | `pool-ssh-daniel-ranya` | distribui as conexões aceitas |
| health monitor | `hm-ssh-daniel-ranya` | TCP a cada 5 s, 3 tentativas |
| member | `vm-daniel-ranya` | `10.5.9.15:22` |

Todos ficaram `ACTIVE`/`ONLINE`. A porta externa **2222** foi escolhida depois de
olhar a lista de listeners em T1.5: já havia SSH em 22, 2201 e 22022 de outros
grupos, então 2222 era a faixa livre mais próxima.

O monitor de saúde é TCP e não HTTP porque o que está sendo balanceado é SSH; um
monitor HTTP em `/health` não faria sentido nessa porta.

## Saída

```text
| baeba4af-2976-4ca9-ba2c-6c51bff598ae | ssh-daniel-ranya | TCP | 2222 |
| a14c8230-7b4a-4b93-a661-c85045eac7bb | vm-daniel-ranya | 10.5.9.15 | 22 | ONLINE |
```

## Decisões

- Protocolo TCP puro, sem terminação TLS: é uma sessão SSH pass-through.
- Porta externa 2222, livre entre os grupos.
