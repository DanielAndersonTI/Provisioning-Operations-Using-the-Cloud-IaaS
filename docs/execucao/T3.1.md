## Objetivo

Liberar apenas o tráfego de que a VM precisa: SSH vindo do balanceador, HTTP das
aplicações também vindo do balanceador e ICMP para diagnóstico. Sem grupo
próprio, a VM herdaria o grupo `default` do projeto, que é compartilhado com
todos os outros grupos.

## Comandos executados

```bash
openstack security group create sg-daniel-ranya -d "Acesso do balanceador a VM - Atividade 3 POI"
openstack security group rule create --protocol tcp --dst-port 22:22 --remote-ip 10.5.8.0/22 sg-daniel-ranya
openstack security group rule create --protocol tcp --dst-port 8000:8002 --remote-ip 10.5.8.0/22 sg-daniel-ranya
openstack security group rule create --protocol icmp --remote-ip 10.5.8.0/22 sg-daniel-ranya
openstack security group show sg-daniel-ranya
```

## O que aconteceu

O grupo `sg-daniel-ranya` (`d60a7836-d518-48c3-ba7b-ebd0085ed208`) ficou com
três regras de entrada e as duas regras de saída que o Neutron cria
automaticamente:

| Direção | Protocolo | Porta | Origem | Para quê |
| --- | --- | --- | --- | --- |
| entrada | TCP | 22 | 10.5.8.0/22 | SSH pela VIP do balanceador |
| entrada | TCP | 8000-8002 | 10.5.8.0/22 | as três aplicações |
| entrada | ICMP | — | 10.5.8.0/22 | `ping` para diagnóstico |
| saída | qualquer | — | qualquer | atualizações e respostas |

A origem é a sub-rede **10.5.8.0/22** e não `0.0.0.0/0` porque a VM não é
alcançável pela internet: quem fala com ela é o amphora do balanceador, que vive
nessa sub-rede. Restringir a origem reduz a superfície de ataque sem tirar nada
do funcionamento.

As três portas 8000-8002 foram abertas de uma vez porque os serviços internos são
fixos (cpu=8000, memory=8001, io=8002), definidos no `systemd` da fase 5.

## Saída

```text
| id              | d60a7836-d518-48c3-ba7b-ebd0085ed208 |
| name            | sg-daniel-ranya |
| rules           | ... direction='ingress', port_range_max='8002', port_range_min='8000', protocol='tcp', remote_ip_prefix='10.5.8.0/22' ... |
```

## Decisões

- Restringir a origem à sub-rede `10.5.8.0/22` em vez de abrir para qualquer IP.
- Não liberar a porta 80: a aplicação não usa porta privilegiada.

Nenhum.
