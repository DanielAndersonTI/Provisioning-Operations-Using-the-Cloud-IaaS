## Objetivo

Confirmar que o caminho externo da Atividade 3 (`poi-atividades`) continua funcionando sem alteração depois do cutover para containers.

## Comandos

```bash
for p in 8100:CPU 8101:MEMORY 8102:IO; do curl http://150.165.85.77:$port/health; done
curl "http://150.165.85.77:8100/work?size=10"
openstack loadbalancer member list pool-app-cpu-daniel-ranya
```

## O que aconteceu

Os três listeners entregaram `200` com latência de ~50 ms, e `/work` respondeu `200` com os perfis corretos. Os três membros (`10.5.9.15` nas portas 8000, 8001 e 8002) estavam `ONLINE`, sem nenhuma mudança de configuração no `poi-atividades`.
