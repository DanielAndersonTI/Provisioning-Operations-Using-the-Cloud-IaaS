## Objetivo

Consolidar o relatório da Atividade 4 com os números reais da execução, regenerar o manifesto de evidências e deixar prontos os dados do formulário de entrega.

## Comandos

```bash
python scripts/make_manifest.py
ls evidencias/ | grep -E '^T(2[4-9])\.' | grep '\.txt$' | wc -l
grep -cE '^T(2[4-9])\.' evidencias/manifest.csv
```

## O que aconteceu

O `RELATORIO-ATIVIDADE4.md` foi preenchido com versões de Docker e Compose, IDs, tamanhos e digests das imagens, URLs do Docker Hub, portas, resultados das verificações, tempos de failover, snapshot e dificuldades. Os 14 registros de tarefa em `docs/execucao-atividade4/` foram preenchidos a partir das transcrições, e o `INDEX.md` passou a marcar T24.1–T29.1 como concluídas. O manifesto foi regenerado.

## Saída

```text
357 linhas, 93 tasks, 0 textos sem print
escrito em evidencias/manifest.csv

51 arquivos .txt de evidência em T24–T29
51 arquivos .png correspondentes
```

## Decisões

O manifesto é a evidência da fase: ele indexa todas as transcrições e prints, por tarefa, com tamanho e dimensões, e mostra que nenhum texto ficou sem print. A tabela do Apêndice A reúne os dados que o formulário pede, para que a resposta seja copiada sem retrabalho.

## Problemas

Nenhum. O commit e o push das mudanças finais são feitos manualmente pelo autor, sem coautoria automatizada; o PR #1 já está aberto para `main` e recebe os novos commits da branch. A matrícula é a única informação do Apêndice A que depende do autor.
