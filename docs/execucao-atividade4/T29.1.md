## Objetivo

Consolidar o relatório da Atividade 4 com os números reais da execução, regenerar o manifesto de evidências e deixar prontos os dados do formulário de entrega.

## Comandos

```bash
python scripts/make_manifest.py
ls evidencias/ | grep -E '^T(2[4-9])\.' | grep '\.txt$' | wc -l
grep -cE '^T(2[4-9])\.' evidencias/manifest.csv
```

## O que aconteceu

O `RELATORIO-ATIVIDADE4.md` foi preenchido com versões de Docker e Compose, IDs, tamanhos e digests das imagens, URLs do Docker Hub, portas, resultados das verificações, tempos de failover, snapshot e dificuldades. Os 13 registros de tarefa em `docs/execucao-atividade4/` foram preenchidos a partir das transcrições, e o `INDEX.md` passou a marcar T24.1–T28.1 como concluídas. O manifesto foi regenerado.

## Saída

```text
352 linhas, 92 tasks, 0 textos sem print
escrito em evidencias/manifest.csv

46 arquivos .txt de evidência em T24–T29
46 arquivos .png correspondentes
```

## Decisões

O manifesto é a evidência da fase: ele indexa todas as transcrições e prints, por tarefa, com tamanho e dimensões, e mostra que nenhum texto ficou sem print. A tabela do Apêndice A foi organizada na ordem do formulário para que a resposta seja copiada sem retrabalho.

## Problemas

Nenhum. A matrícula e a URL do pull request são as duas informações que dependem do autor e ficam marcadas no Apêndice A; o commit e o PR são manuais, sem coautoria automatizada.
